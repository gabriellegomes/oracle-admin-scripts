# 🏛️ Oracle Admin Scripts

Coleção de scripts SQL para uso no Oracle SQL Developer.


## 📂 Estrutura de pastas:

⚙️ administration → tarefas administrativas (usuários, permissões, tablespaces)

🚀 performance → tuning, estatísticas, índices, planos de execução

🩺 diagnostics → scripts de diagnóstico e análise de performance

🧱 structure → estrutura de objetos (tabelas, colunas, constraints)

🧰 utils → utilitários diversos e consultas rápidas


## 💡 Uso:
Abra o SQL Developer → execute o script desejado → visualize os resultados diretamente no editor.
